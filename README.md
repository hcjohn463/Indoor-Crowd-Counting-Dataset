# Indoor Crowd Counting Dataset
### Pseudo-Label Optimization for Indoor People Counting

This repository contains all training and evaluation data used in the thesis:

> **"Pseudo-Label Optimization for Indoor People Counting"**

The dataset supports a **Teacher–Student fine-tuning framework** for indoor crowd counting, where a pre-trained teacher model generates pseudo-labels that are used to adapt a student model to new indoor scenes with minimal manual annotation.

## 🔬 Experimental Setup: Fine-tuning Subsets

The student model is fine-tuned using subsets of pseudo-labeled images from each scene. Experiments are conducted at the following data scales:

| Subset Size | Description |
|-------------|-------------|
| **50** | Very limited labeled data |
| **100** | Small-scale annotation |
| **200** | Medium-scale annotation |
| **400** | Moderate annotation budget |
| **700** | Large annotation budget |

Each subset is sampled from the pseudo-labeled data (e.g., `scene1_girl1/`). The 100-image hand-labeled sets serve as the **test split** for evaluation across all experiments.

---

## 📂 File Format

Each sample in this dataset consists of two paired files:

| File | Description |
|------|-------------|
| `images/{id}.jpg` | RGB image frame extracted from video |
| `density_maps/{id}.h5` | Gaussian density map (HDF5 format, key: `density`) |

The density map is generated by convolving head-center point annotations with a Gaussian kernel. The integral of the density map gives the estimated crowd count.

**Example — loading a density map in Python:**
```python
import h5py
import numpy as np

with h5py.File('density_maps/1.h5', 'r') as f:
    density = np.array(f['density'])

crowd_count = density.sum()
print(f"Estimated count: {crowd_count:.1f}")
```

## 📋 Annotation Details

### Teacher Training Data (`lab_scene`)
- **Source**: Self-collected laboratory environment video recordings (National Taiwan Normal University)
- **Total frames**: 1,508 images
- **Annotation method**: Manual head-point annotation → Gaussian density map
- **Density map format**: HDF5 (`.h5`), key `density`, shape `(H, W)`, dtype `float32`

### Student Pseudo-Labels (`scene1_girl1`, `scene2_girl2`, `scene3_girl3`)
- **Source**: Frames extracted from the **Classroom Group Engagement (CGE) dataset** — Lu et al., *Scientific Data*, 2025 [[paper]](https://doi.org/10.1038/s41597-025-04987-w)
- **Annotation method**: CLIP-EBC based pseudo-label generation (optimized by this work)
- **Usage**: Fine-tuning subset experiments (N = 50, 100, 200, 400, 700)

### Student Hand Labels (`*_100` folders)
- **Source**: Frames from the same CGE dataset (Lu et al., 2025)
- **Total**: 100 images per scene (300 total)
- **Annotation method**: Manual head-point annotation → Gaussian density map
- **Usage**: **Test split only** — not used in any training


## 📌 Notes

- The three student scenes (`scene1`, `scene2`, `scene3`) are **independent indoor environments**, each recorded under different lighting and crowd conditions.
- The pseudo-labels in this dataset have been **optimized** using a CLIP-EBC based algorithm, which is the core contribution of the thesis.
- Hand-labeled sets are used **exclusively for evaluation** and represent the ground truth.
- Fine-tuning subsets (50/100/200/400/700 images) are **sampled from the pseudo-labeled pool**, not from the hand-labeled sets.
