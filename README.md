# Indoor Crowd Counting Dataset

A dataset of indoor laboratory environment images for people counting, designed for training and evaluating **student models** in indoor crowd counting tasks.

---

## 📁 Repository Structure

```
indoor-crowd-counting-dataset/
│
├── lab_scene/           # Lab environment images
│   ├── images/          # Raw frames (.jpg)
│   └── density_maps/    # Manually annotated density maps (.h5)
│
└── README.md
```

## 📂 File Format

Each sample consists of two paired files:

| File | Description |
|------|-------------|
| `images/{id}.jpg` | RGB image frame extracted from video |
| `density_maps/{id}.h5` | Gaussian density map (HDF5 format, key: `density`) |

The density map is generated by convolving head-center point annotations with a Gaussian kernel. The integral of the density map equals the estimated crowd count.

**Example — loading a density map in Python:**
```python
import h5py
import numpy as np

with h5py.File('density_maps/1.h5', 'r') as f:
    density = np.array(f['density'])

crowd_count = density.sum()
print(f"Estimated count: {crowd_count:.1f}")
```

## 🔬 Annotation Details

- **Source**: Self-collected laboratory environment video recordings (National Taiwan Normal University)
- **Total frames**: 1,508 images
- **Annotation method**: Manual head-point annotation converted to Gaussian density maps
- **Density map format**: HDF5 (`.h5`), key `density`, shape `(H, W)`, dtype `float32`

## 🛠 Requirements

To work with the `.h5` density maps:

```bash
pip install h5py numpy
```

To visualize density maps:

```bash
pip install matplotlib
```

**Example visualization:**
```python
import h5py
import numpy as np
import matplotlib.pyplot as plt
from PIL import Image

img = Image.open('images/1.jpg')
with h5py.File('density_maps/1.h5', 'r') as f:
    density = np.array(f['density'])

fig, axes = plt.subplots(1, 2, figsize=(12, 5))
axes[0].imshow(img)
axes[0].set_title('Input Image')
axes[0].axis('off')

axes[1].imshow(density, cmap='jet')
axes[1].set_title(f'Density Map (Count: {density.sum():.1f})')
axes[1].axis('off')
plt.tight_layout()
plt.show()
```
